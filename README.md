# FocusMode — تحسينات محلية لـ HelloTalk 6.3.51

دايلب واحد فيه ميزتين:

1. **وضع تركيز** (`FocusMode.m`) — يحجب محلياً على جهازك كل عرض إعلان يرث
   من `BaseADView` (اللي يظهر داخل اللحظات وقائمة المحادثات وشاشات أخرى).
   لا يلمس الشبكة، ولا يعدّل أي استجابة من سيرفر HelloTalk، ولا يفعّل أي
   ميزة مدفوعة.
2. **زر قائمة عائم + قاموس** (`HTMenu.m`) — زر دائري تقدر تسحبه فوق أي
   شاشة بالتطبيق، يفتح قائمة خيارات وفيها "📖 القاموس": بحث إنجليزي مستقل
   تماماً (يستخدم قاموس مجاني مفتوح على الإنترنت، لا علاقة له بحساب أو
   سيرفرات HelloTalk).

## 1. الإنشاء على GitHub

1. أنشئ مستودع جديد باسم `FocusMode` تحت حسابك `polatmsmakm-ctrl`.
2. ارفع له الملفين: `FocusMode.m` ومجلد `.github/workflows/build.yml`.
3. من تبويب **Actions** شغّل الـ workflow (أو push لفرع main وبيشتغل تلقائي).
4. بعد ما يخلص، نزّل الملف من **Artifacts** → `FocusMode.dylib`.

## 2. الحقن بملف HelloTalk المفكوك

1. فك ضغط ملف الـ IPA (المفكوك اللي رفعته لي، إصدار 6.3.51).
2. انسخ `FocusMode.dylib` إلى: `Payload/HelloTalk_Binary.app/Frameworks/`
3. أضف تحميل الدايلب للملف التنفيذي الرئيسي (`HelloTalk_Binary`) بأداة
   مثل `insert_dylib` أو `optool`:
   ```
   insert_dylib --inplace --all-yes \
     @executable_path/Frameworks/FocusMode.dylib \
     Payload/HelloTalk_Binary.app/HelloTalk_Binary
   ```
4. أعد ضغط المجلد لملف `.ipa`.

## 3. التوقيع والتثبيت

وقّعه وثبّته بـ Sideloadly بنفس الطريقة اللي تستخدمها لباقي تطبيقاتك.
تذكير: الصلاحيات المرتبطة بحساب مدفوع (Apple Pay، iCloud) غالباً تُشال
عند التوقيع بحساب مجاني — هذا طبيعي وما يأثر على عمل الدايلب.

## 4. التأكد إنه شغال

افتح التطبيق، روح لتبويب اللحظات أو قائمة المحادثات. إذا ما طلعت أي
مساحة فاضية أو إعلان، فهو شغال. تقدر كذلك تتابع سجل الجهاز (Console)
وتشوف السطر:
```
[FocusMode] تم التفعيل — إعلانات BaseADView محجوبة محلياً.
```

## ملاحظة على التحديثات

هذا الدايلب مبني على أسماء كلاسات استخرجتها من ملف 6.3.51 بالذات. أي
إصدار جديد من HelloTalk قد يغيّر هذي الأسماء، فالدايلب ما يشتغل تلقائياً
على إصدار أحدث — لازم إعادة فحص الإصدار الجديد أولاً.
